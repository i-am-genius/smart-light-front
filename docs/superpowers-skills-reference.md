# Superpowers Skills 参考 (v5.1.0)

## 流程类

| 命令 | 用途 |
|------|------|
| `/brainstorming` | 写代码前讨论方案、需求、设计 |
| `/writing-plans` | 多步骤任务先写实施计划 |
| `/executing-plans` | 按计划分步执行实施 |
| `/test-driven-development` | TDD 方式先写测试再写实现 |
| `/verification-before-completion` | 改完代码后验证通过再声称完成 |
| `/requesting-code-review` | 请求代码审查 |
| `/receiving-code-review` | 收到审查意见后的处理 |
| `/finishing-a-development-branch` | 开发完成，决定合入方式 |

## 支撑类

| 命令 | 用途 |
|------|------|
| `/systematic-debugging` | 遇 bug 系统排查，找根因 |
| `/using-git-worktrees` | 创建隔离工作区 |
| `/dispatching-parallel-agents` | 并行派发多个 subagent |
| `/subagent-driven-development` | 用 subagent 执行计划中的独立任务 |
| `/writing-skills` | 创建或编辑技能文件 |
| `/using-superpowers` | 技能系统使用说明（基础） |
