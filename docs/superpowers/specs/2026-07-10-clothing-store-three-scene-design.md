# 精品服装店 3D 灯光场景设计

## 目标

在不改变 `ThreeLightingLayout.vue` 的任何设备数据、分区状态、拖拽、选中、持久化、定位或相机切换逻辑的前提下，将现有 3D 视图升级为暖色高级感的精品服装店灯光展示场景。

## 视觉方向

采用“暖调精品服装店”而非通用设备展厅：暖灰织物/微水泥墙面、浅橡木拼接地板、香槟金细节和柔和暖白照明构成背景；射灯和服装仍是画面焦点。场景保留干净留白，避免新增物件遮挡可拖动的轨道或灯具。

调色板：

- 墙面暖灰：`#D9D0C4`
- 浅橡木：`#B78559`
- 香槟金：`#C8A56C`
- 深炭金属：`#26313A`
- 暖白光：`#FFF1D6`

## 场景与材质

`createStoreSpace` 只使用 Three.js 的程序化几何和材质，不下载或引入贴图资源：

- 地面增加交错木板、细微色差、拼缝和低反射罩光，保留现有接收阴影能力。
- 背墙改为三组服装陈列墙：暖灰软包/微水泥底板、香槟金框线、衣杆、展示台和低调品牌铭牌；衣架与服装陈列延续现有按灯位生成的服装模型。
- 补充侧向暖光、顶棚洗墙光与局部泛光，强化衣物、金属轨道及地面材质层次，控制亮度以免干扰由设备亮度驱动的射灯光束。
- 射灯模型增加拉丝金属层、散热片、铭牌环、玻璃透镜和柔和的暖色高光；选中环、拖拽命中范围以及灯光目标计算保持不变。
- 保持现有相机预设、雾效、投影、渲染循环和响应式尺寸逻辑，仅调整色彩管理、阴影细节和背景氛围参数。

## UI

仅调整模板的样式和非交互性视觉标记，不修改任何既有按钮、`@click`、禁用条件、文本数据源或组件事件：

- 顶部控制区升级为深暖色半透明玻璃控制台，分区切换成为带金色细线的胶囊组件。
- 视图切换按钮采用紧凑的“镜头”控制风格；在视口内增加不拦截指针的场景信息角标和拖拽提示。
- 强化悬停、键盘焦点、禁用态及夜间模式对比度；减少动画偏好下停用非必要的装饰性动画。
- 移动端保持现有 360px 视口高度，并让控制区自然换行，避免遮挡 3D 画布。

## 逻辑与兼容性约束

- 不更改 props、emits、类型、设备筛选、localStorage 键或存储结构。
- 不更改 `switchZone`、灯位增删排序、射灯拖拽、选中回调、`locateDevice` 调用、相机预设和视图切换行为。
- 不添加网络请求、第三方依赖、外部纹理或静态资源。
- 继续使用 `disposeObject` / `disposeMaterial` 处理新建 Mesh 的资源释放；共享材质仅在现有生命周期内使用。

## 验证

- 为只读源码结构增加最小自动化检查：确认核心交互处理函数、持久化键、`selection-change` 事件和既有按钮事件仍然存在；先观察该检查在新场景标记缺失时失败，再实现视觉标记后使其通过。
- 执行 TypeScript/Vite 生产构建，确保不引入类型或打包错误。
- 启动本地页面进行人工视觉核验：确认暖色服装店氛围、三种设备灯光色温、选中与拖拽状态、展示/调节视角、分区切换和移动端布局均正常。

## 范围外

- 不新增商品、价格、库存、顾客或门店配置数据。
- 不改变服装颜色与设备数据之间的既有映射。
- 不重构该组件的业务逻辑，也不修改工作区中的其他文件或未提交改动。
