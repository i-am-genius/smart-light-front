# 日夜模式图标连续形变设计

**日期：** 2026-07-22

## 目标

优化店铺设置页日夜模式按钮的图标切换。现有实现叠放两个字体符号，并同时执行缩放与透明度切换；太阳和月亮的字形、基线及视觉重量不一致，切换中也没有共享的运动轨迹，因此显得跳变。

完成后的图标应满足：

- 日间与夜间共享同一个 SVG 图形主体，切换过程可连续追踪。
- 动效活泼、有轻微弹性，但不影响控制台的克制感。
- 日转夜与夜转日使用完全可逆的时间轴。
- 按钮尺寸和文字位置在切换中保持稳定。
- 系统启用“减少动态效果”时仍能清晰表达当前状态。

## 交互与图形

主题按钮保留现有点击行为、`aria-pressed` 和“日间 / 夜间”文字，只替换图标结构与动画。

图标使用一个 `24 x 24` 的内联 SVG：

- 一个中心圆盘同时承担太阳核心与月亮主体。
- 八条等长短光芒围绕中心圆盘，保持统一线宽和圆角端点。
- SVG 遮罩中的切口圆从右上方滑入中心圆盘，把完整圆盘连续切成月牙。
- 一颗小星位于月牙右上方，只在夜间阶段出现。

日间采用暖金色，夜间采用冷蓝色。颜色只作用于图标，不扩大页面现有配色范围。

## 动效时间轴

完整切换约 `420ms`，由按钮的 `is-night` 状态驱动：

1. `0-180ms`：太阳光芒旋转并向圆心收拢，透明度逐渐降为零。
2. `80-300ms`：遮罩切口从圆盘外滑入，同时主体从暖金过渡为冷蓝。
3. `240-420ms`：小星从缩小、轻微偏移的状态弹入；图标主体以约 `1.06` 倍轻微过冲后归位。

夜转日使用相同 CSS 状态的反向过渡，不增加单独的 JavaScript 动画状态，避免快速重复点击时出现方向错乱或图标卡在中间态。

## 实现边界

改动限制在：

- `src/components/settings/StoreSettingsPanel.vue`：替换主题图标模板并添加 scoped CSS。
- 对应的源码结构测试：约束单 SVG、遮罩、光芒、星点、时长和减少动态效果规则。

不修改 `StoreSettingsValue`、`toggleMode()`、父组件状态持久化或全局日夜主题样式。

SVG 遮罩使用组件内固定 ID。页面只渲染一个 `StoreSettingsPanel` 实例，因此不会产生重复 ID 冲突。

## 无障碍与兼容性

- 按钮继续暴露 `aria-label` 与 `aria-pressed`，SVG 保持 `aria-hidden="true"`。
- 键盘焦点、触控热区和按钮文本不变。
- `prefers-reduced-motion: reduce` 下禁用旋转、位移和弹性缩放，仅保留当前状态的静态最终图形；颜色切换可即时完成。
- 动画只使用 SVG 基本图元、遮罩和 CSS `transform` / `opacity` / `color`，不依赖 SVG `d` 路径插值，避免浏览器插值差异。

## 验证

自动化验证：

- 测试确认主题图标只包含一个 SVG，而不是字体太阳/月亮符号。
- 测试确认 SVG 包含中心主体、遮罩切口、八条光芒和星点。
- 测试确认夜间状态及减少动态效果规则存在。
- 运行相关测试和完整生产构建。

视觉验证：

- 在桌面和移动视口分别检查日间与夜间最终状态。
- 实际点击并观察两个方向的连续性、回弹幅度和文字稳定性。
- 快速连续点击，确认动画能从当前插值状态自然反向，不闪烁、不跳位。
- 检查 SVG 没有裁切、按钮内容没有溢出或改变布局。
